## Recent updates worth watching

- **GitHub Agentic Workflows (gh-aw)** lets teams define AI agent automations as markdown files with YAML frontmatter, compiled into GitHub Actions workflows, with built-in "safe outputs" (e.g., add-comment, create-issue) to keep agent writes reviewable and sandboxed. (Source: [github/gh-aw guidance](https://raw.githubusercontent.com/github/gh-aw/main/.github/aw/github-agentic-workflows.md))
- **Refreshed repository pull requests page** is in public preview, giving PR lists a modernized look and navigation. (Source: [GitHub Changelog](https://github.blog/changelog/))
- **Auto-resolution and analysis updates in Copilot code review**, following Copilot Code Review's new ability to approve pull requests — code review is getting more autonomous. (Source: [GitHub Changelog](https://github.blog/changelog/))
- **Configure cost and quality in Copilot auto model selection**, giving teams more control over which models Copilot picks for a given task. (Source: [GitHub Changelog](https://github.blog/changelog/))
- **Control GitHub Actions cache access with `cache-mode`**, a new way to restrict which workflows can read or write the Actions cache. (Source: [GitHub Changelog](https://github.blog/changelog/))
- **"Decoding the new AI lingo"** and **"How we make AI coding more cost efficient without sacrificing task quality"** unpack agent terminology (loops, harnesses, squads) and cost-efficiency techniques for AI coding assistants. (Source: [GitHub Blog](https://github.blog/latest/))
